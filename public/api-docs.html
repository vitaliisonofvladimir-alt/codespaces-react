NVVAI public site API

These endpoints support the public chat interface. The machine-readable OpenAPI specification describes their requests and responses.

Text responses

Send POST /api/chat or POST /api/agent with Content-Type: application/json and a JSON body such as {"message":"Hello"}. Both currently return {"reply":"..."}. An empty message cannot be processed.

Audio transcription

Send POST /api/transcribe with the audio bytes as the body and a matching audio content type, such as audio/webm. The maximum recording size is 10 MiB. The JSON response contains a text string.

Errors

Errors are JSON objects with an error string. Audio exceeding the size limit receives HTTP 413; processing failures receive HTTP 500. These endpoints are intended for the public site and may change as its features evolve.
